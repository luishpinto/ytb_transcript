# ytb_transcript

A lightweight Python library to fetch, parse, and structure YouTube video transcripts in a clean and programmatic way.

## Overview

`ytb_transcript` provides a simple interface to retrieve transcripts from YouTube videos and transform them into structured data formats suitable for downstream processing, such as:

- Natural Language Processing (NLP)
- Data analysis
- Content summarization
- AI pipelines and agents

The project is organized with a modular architecture, where the `core` package contains the main logic for transcript extraction and processing.
